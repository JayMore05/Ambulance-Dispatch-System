# 🚑 Smart-Response: Real-Time Ambulance Dispatch System

### 🚀 Project Overview
A distributed full-stack application designed to coordinate life-saving medical dispatches between patients, emergency drivers, and specialized hospital departments.

---

### 🧠 Core Engineering Challenges
* **Geospatial Intelligence:** Implemented the **Haversine Formula** to calculate precise distances between patient GPS coordinates and nearby medical facilities.
* **Atomic Concurrency Control:** Developed a server-side lock in Node.js/MySQL to prevent "Race Conditions" during driver assignment.
* **State-Driven Workflow:** Engineered a dual-app architecture that manages the mission lifecycle from initial request to hospital dropoff.

---

### 🛠️ Tech Stack
* **Runtime:** Node.js
* **Backend:** Express.js
* **Database:** MySQL
* **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3
* **Navigation:** Google Maps Universal URI Scheme
